garlic collects R functions I use frequently in my own projects. It includes tools for checking missing values and describing data, modifying selected variables, and applying my ggplot2 themes.

The package documentation includes separate vignettes for exploratory functions, data manipulation, and the plotting theme.

Install it from GitHub:

```r
devtools::install_github("harshvardhaniimi/garlic")
library(garlic)
```
